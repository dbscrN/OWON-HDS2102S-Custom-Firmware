# Кастомная прошивка для портативного осциллографа-мультиметра OWON HDS2102S

[English](README.md) | **Русский**

Неофициальная модификация прошивки **V4.7.1** портативного осциллографа-мультиметра **OWON HDS2102S** (аппаратный вариант `HDS2102S_LS`), а также инструменты, которыми она сделана: распаковщик пакета `.upp`, дизассемблер-обвязка, патчер палитры и сборка надстройки на C.

> **Внимание.** Всё здесь — на ваш страх и риск. Прошивка проверена на одном приборе. Неудачная прошивка может превратить прибор в кирпич: способ восстановления без программатора неизвестен. Подходит только для варианта `HDS2102S_LS` с прошивкой V4.7.1 — у этой модели есть несовместимые аппаратные ревизии.

## Что добавлено

- **График измеряемой величины в режиме мультиметра** — 120 точек, окно 30 с / 1 мин / 5 мин / 30 мин, шкала подстраивается под минимум и максимум за окно.
- **Минимум и максимум** за окно рядом с показанием.
- **Частота на переменном напряжении** (Hz / kHz / MHz) — мультиметр переключается между напряжением и частотой.
- **Пауза графика** при удержании показания (Hold), при перегрузке (`OL`) и на время смены диапазона.
- **Меню графика** на кнопках F1–F4, вызывается клавишей `HOR`.
- Вариант с **красной палитрой** интерфейса вместо синей.
- Интерфейс только на **английском** (остальные языки перенаправлены на английские строки).

## Управление

В режиме мультиметра клавиша `HOR` открывает меню на нижних кнопках:

| Кнопка | Действие |
|---|---|
| F1 `Trend` | включить / выключить график |
| F2 `Time` | длительность окна: 30s → 1min → 5min → 30min |
| F3 `Freq` | на переменном напряжении: напряжение ↔ частота |
| F3 `Clear` | в остальных режимах: очистить график |
| F4 `Close` | закрыть меню (то же делает повторное `HOR`) |

Пока меню открыто, внутри графика видна служебная строка — сырые байты последнего кадра от контроллера мультиметра.

## Готовые прошивки

| Папка | Что это | Сумма в «System → About» |
|---|---|---|
| `firmware/stock/` | оригинальная V4.7.1 | `2601FC70` |
| `firmware/trend-red/` | график + частота, красная палитра | `61C604B7` |
| `firmware/trend-blue/` | график + частота, штатная синяя палитра | `CF2AD55D` |

Файл в каждой папке называется `Scope.upp` — под этим именем его принимает прибор.

### Как прошить

1. В настройках прибора включите режим USB «MSC» (накопитель) — без этого компьютер не увидит его как диск.
2. Подключите прибор к компьютеру по USB, он появится как диск.
3. Скопируйте на него нужный `Scope.upp`.
4. На приборе откройте `System → About` и выберите пункт `Upgrade`.
5. Перезагрузите прибор — обновление выполнится при запуске.
6. Проверьте контрольную сумму в `System → About`: она должна совпасть с таблицей выше.

Вернуться назад можно, прошив `firmware/stock/Scope.upp`, — пока прибор загружается и принимает обновления.

## Сборка из исходников

Нужны Python 3 с пакетом `capstone` и компилятор `arm-none-eabi-gcc` (Arm GNU Toolchain).

```bash
pip install -r requirements.txt
```

```bash
python tools/upp_tool.py unpack firmware/stock/Scope.upp unpacked
```

```bash
python tools/patch_palette.py build red 3=C81010
```

```bash
python tools/build_trend.py trend --base build/red
```

Результат — `build/trend/Scope.upp`. Без `--base build/red` получится вариант со штатной палитрой; ключ `--keep-langs` оставляет все языки. Ожидаемую сумму для любой сборки считает `python tools/device_checksum.py build/trend`.

## Ограничения

- Напряжение и частоту одновременно контроллер мультиметра не отдаёт — только что-то одно.
- Частота измеряется, только если сигнала достаточно для входа мультиметра (калибровочный выход прибора слишком слаб).
- График обновляется с темпом мультиметра, около 3,5 отсчёта в секунду: короткие импульсы он не покажет.
- Настройки графика не сохраняются после выключения.
- Код надстройки лежит на месте таблицы иероглифов 18 px, поэтому китайский и японский интерфейс в этой сборке не поддерживаются.
- Опасная SCPI-команда `:SECurity` меняет защиту чтения микроконтроллера — не отправляйте её.
